# FUTURE_DS_01 — Business Sales Performance Analytics

## 📌 Task Overview
This repository contains **Task 1** of the Future Interns Data Science & Analytics Internship. The task focuses on analyzing business sales data to identify revenue trends, top-selling products, high-value categories, and regional performance.

## 🎯 Objective
Analyze the Sample Superstore Sales dataset (2014–2017) and build a client-ready dashboard with actionable insights.

## 🛠️ Tools Used
- Microsoft Excel (Pivot Tables, Charts, Dashboard)
- Data Cleaning & KPI Analysis

## 📂 Files
| File | Description |
|------|-------------|
| `Task_1_Sales_Analysis.xlsx` | Excel dashboard with pivot tables and charts |
| `Task_1_Sales_Analysis_Report.pdf` | Report with key insights and recommendations |
| `screenshots/` | Dashboard and insights screenshots |

## 📊 Key Insights
1. Revenue grew consistently from 2014 to 2017, peaking at ~7.3M in 2017.
2. Technology is the most profitable category (Sales: 8.36M, Profit: 1.45M).
3. Furniture has very low profit margin (Sales: 7.4M, Profit: only 18K).
4. West region is the top performer (Sales: 7.25M, Profit: 1.08M).
5. Canon Imageclass 2200 Advanced Copier is the top revenue-generating product (~61.6K).

## ✅ Recommendations
1. Increase inventory and marketing for Technology category top products.
2. Reduce discounts on Furniture to improve profit margins.
3. Launch targeted marketing campaigns for the South region.
4. Maintain optimal inventory for top-selling products.
